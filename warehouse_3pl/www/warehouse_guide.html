{{ _("Goods coming in") }}

1

{{ _("Advance notice") }} — ASN

Raise an ASN when a client tells you a shipment is on the way, before it reaches the gate. Record what is expected and how much, plus lot and expiry where it matters. This step is optional — goods that arrive unannounced can be received directly.

2

{{ _("Receiving at the dock") }} — Receiving

Count what actually arrived: received quantity, rejected quantity, and the condition of each line — Good, Damaged, Short or Over. Name the staging area the goods stand in.

{{ _("On submit the system") }}:
  • {{ _("books the stock into the staging warehouse") }}
  • {{ _("raises a putaway task for every line") }}
  • {{ _("marks the ASN received and updates the job record") }}
3

{{ _("Putaway to the racks") }} — Putaway Task

Each task carries a suggested destination chosen from the client's inventory policy — temperature zone, dedicated area, remaining weight and volume. Override it if the floor says otherwise. Completing the task moves the stock and makes it pickable.

{{ _("Goods going out") }}

4

{{ _("The client's order") }} — Client Order

{{ _("Record what the client wants shipped, the ship-by date and a priority.") }}

5

{{ _("Planning the run") }} — Wave

Group orders going out together, typically everything for one carrier cut-off. Releasing the wave reserves stock oldest-first and raises pick tasks with the exact locations to pull from.

6

{{ _("Picking and packing") }} — Pick Task, Pack Task

The picker marks each line Picked or Short; start and finish times are recorded. Completing the pick raises the pack task. Record cartons and total weight there.

{{ _("Completing the pack task creates the outbound delivery note and marks the order shipped.") }}
7

{{ _("Handing over") }} — Delivery Note

Add the carrier, tracking number and bill of lading. The delivery note carries no goods value — the stock was never yours — so it moves inventory without touching revenue.

A rate card per client turns warehouse activity into money. Each line is an activity, a unit and a rate, with an optional minimum charge. Cards carry an effective-from date, so a price change is a new card rather than an edit that rewrites history. Only cards marked Active price anything.

{{ _("Two things to know about billing") }}

{{ _("Handling activities are currently set to zero.") }} {{ _("Receiving, picking, packing and shipping have no per-unit rate on the active cards, so no charge line is written for them. Handling continues to be invoiced as a lump sum per shipment, as before. Fill in the rates on the rate card to switch that on.") }}
